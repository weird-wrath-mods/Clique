- User asked what properties of WoW's focus unit slot allow it to solve the targeting issue that other unit slots cannot.
- Claude Code explained that focus has three critical properties: it is writable from macros (`/focus <unit>`), synchronously updated within a single macro execution (unlike `lasttarget` which updates asynchronously between frames), and independent from the target unit (unlike `targettarget`, `focustarget`, `pettarget` which are derived and change when their base unit changes).
- Claude Code noted that the combination of all three properties—writable + synchronous + independent—is unique to focus and enables using it as a save register: write the current target into focus, mutate target freely to consume cursor or cast, then restore target by reading focus back.
- Claude Code identified that no other unit slot possesses all three properties, making focus the only viable mechanism for this workaround.
- Claude Code noted the constraint: having focus already in use for another purpose blocks this solution because it would require overwriting the only available save register.
